# On-call guide

## Severity levels

- **SEV1**: public dashboards unreachable. Page primary and secondary.
- **SEV2**: degraded data freshness > 15 min. Page primary.
- **SEV3**: single-tenant issues. Ticket only.

## Hand-over

The weekly hand-over is Mondays 12:00 UTC in the ops channel; both the
outgoing and incoming primary must acknowledge in writing.
