# Contributing to AuroraKit

Thanks for helping us improve AuroraKit!

## Pull requests

1. Fork the repository and create a topic branch.
2. Follow the [documentation style guide](docs/style-guide.md) for any docs
   changes; the style guide also covers heading hierarchy and front matter.
3. Fill in the [bug report template](.github/ISSUE_TEMPLATE/bug-report.md)
   when your PR fixes a bug.

## Commit conventions

We use conventional commits. Keep the subject line under 72 characters.
