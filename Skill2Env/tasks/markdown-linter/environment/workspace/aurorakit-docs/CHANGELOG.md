# Changelog

All notable changes to AuroraKit are documented here.

## [1.0.0] - 2024-03-12

The "Constellation" release restructured the documentation tree. Every page
was moved to its final location; see the [migration map][migration-map] for
the authoritative old-to-new path table maintained by the docs team.

### Added

- AuroraKit CLI with device-code authentication.
- `aurorakit serve --watch` development mode.

### Changed

- Documentation now separates the HTTP bearer token reference from the CLI
  token reference. They used to be one page.

[migration-map]: docs/migration-guide.md
