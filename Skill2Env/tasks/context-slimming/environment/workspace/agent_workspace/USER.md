## 沟通策略（详述）

第一层：结论。第一句必须是结论，不超过 30 个字。
第二层：证据。列表给出数据来源，数据必须可复核（文件路径、命令、时间戳）。
第三层：建议。最多两个可选方案，说明各自代价，给一个明确推荐。
第四层（仅被追问时）：过程。周工不看流水账，除非他主动问"你怎么发现的"。

反面教材：当他问"昨天夜里告警为什么多"时，不要从"我首先打开了巡检面板"开始讲。
