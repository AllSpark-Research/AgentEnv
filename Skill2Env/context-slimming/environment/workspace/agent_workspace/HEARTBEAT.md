# HEARTBEAT.md — 心跳检查（每 15 分钟）

本文件每轮注入。每 15 分钟评估一次下列检查项；只处理落在窗口内且有实际变化的项目，
无事发生就保持沉默——心跳的价值在于不打扰。

## 核心检查清单

1. pearl 平台活动告警：`xray-cli alerts active --json --since 15m`，有新增则聚类后初判，P0 立即唤醒。
2. 工单 SLA：今天到期的工单列表，临期（<2h）才提醒。
3. 周工日程：下一小时内的会议提醒一次；深夜不提醒非 P0 事项。
4. 下载目录：新出现的大文件（>500MB）报告一次即可。
5. 维护窗口：02:00-04:00 期间只保留 P0 检查，其余心跳活动全部静默。

## 历史备注

- 旧版配置为每 30 分钟心跳一次，2025-04 起缩短到 15 分钟，旧配置已废弃。
- 周报草稿生成流（已下线，待清理）：原先每周五 08:00 由心跳触发周报骨架生成，
  自 2025-05 起周报改由 git push 钩子驱动，本流程再无触发方，相关段落仅存档未删。

唤醒周工时必须附：事件一句话、证据链接、已做动作、建议动作。
四样缺一样都不叫唤醒，叫打扰。
