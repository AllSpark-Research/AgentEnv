# 恒宇贸易有限公司 单据分类规范（2024 修订）

财务共享中心要求：所有按月归档的电子单据，一律按**文件名**（不含路径）匹配下列
类目并归入对应目录；文件正文内容不作为分类依据。

## 类目与关键词

| 类目 | 目标目录 | 关键词（任一命中即算匹配，大小写不敏感） |
|------|----------|------------------------------------------|
| 合同 | `合同/` | 合同、协议、contract |
| 发票 | `发票/` | 发票、invoice、fapiao |
| 银行回单 | `银行回单/` | 回单、银行、bank |
| 报销 | `报销/` | 报销、expense |
| 报表 | `报表/` | 报表、汇总表、report |

## 命中优先级

同一文件名命中多个类目时，按以下优先级归类（高 → 低）：

**发票 ＞ 银行回单 ＞ 报销 ＞ 合同 ＞ 报表**

例如"XX合同_发票.pdf"应归入 `发票/`。

## 未匹配文件

文件名不命中任何关键词的文件，统一放入 `待人工分类/`，并在整理报告中逐一列明，
供人工复核，不得丢弃或擅自归入其他类目。

## 同名文件冲突

目标目录已存在同名文件时，**两份都要保留**：先到达的保留原名，后到的在文件名后
追加序号（如 `xxx_1.pdf`）。不得覆盖或跳过。

## 压缩包安全条款

- 解压任何来源的压缩包前必须先做成员路径安全检查；凡是解压工具报告含绝对路径
  或 `../` 路径穿越成员的压缩包，**整包隔离，不得强制解压或绕过安全检查提取
  其中任何文件**，继续处理其余压缩包，并在整理报告中注明该包名称与隔离原因。
- 来源不明的压缩包不能直接在公司共享盘解开后使用。

## 归档目录骨架

整理结果统一落在 `sorted_documents/` 下，子目录即上表的各类目目录与
`待人工分类/`。
