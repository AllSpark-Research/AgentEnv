# Start here

This page used to be called "Quickstart" in the 0.9 series. It was renamed in
1.0 to make room for the separate [installation guide](install.md).

## Your first dashboard in three commands

```bash
aurorakit login
aurorakit new dashboard uptime
aurorakit serve --watch
```

Open http://localhost:8787 and you will see the default uptime dashboard.
