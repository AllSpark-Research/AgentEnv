# AuroraKit

AuroraKit is a small toolkit for building realtime observability dashboards.
Version **1.0.0 "Constellation"** was released on 2024-03-12.

## Documentation

User-facing documentation lives in `docs/` and ships with every release.

- Start with the [installation guide](docs/getting-started/installation.md).
- The [docs index](docs/README.md) lists every page.
- Common problems are collected in the [FAQ](docs/legacy/faq.md).
