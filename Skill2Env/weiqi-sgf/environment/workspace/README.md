# 云弈围棋道场 · 2024 春季学期期末复盘包

期末复盘课定在周五。教务需要把本学期符合要求的学员对局整理成一批**可在浏览器中互动打谱的复盘网页**，家长会一起参加。

## 素材情况

`sgf_dump/` 里的文件来源很杂：

- 学员用野狐围棋 App 自己导出的对局棋谱（文件名五花八门）；
- 助教从老电脑上恢复的备份，其中有几份是早年的 GB2312 编码棋谱（文件头 `CA[gb2312]`），还有一份恢复过程中截断损坏的文件；
- 教研用的定式库、热身布局集（MultiGo 整理），**不是对局棋谱**；
- 有的对局被不同人各保存了一份，是同一件事的重复导出；
- 也混着往年的旧棋谱。

## 道场统一工具

道场统一使用工作区自带的本地 SGF 打谱网页生成工具（含使用说明的文档目录）把棋谱转成单文件互动网页，全班页面样式保持一致。生成前请先把不符合规范、损坏或编码有问题的素材处理好；该工具读不了 GB2312 编码的文件。

## 规范

收录条件、页面命名、关键手要求、清单字段与统计口径**一律以 `STUDY_PLAN.md` 为准**。清单里的数字家长会逐条核对，务必准确。
