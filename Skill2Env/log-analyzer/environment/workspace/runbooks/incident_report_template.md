# Incident Report — INC-XXXX: <short title>

## Summary
One paragraph: what happened, when, and current state (resolved?).

## Impact
Customer-facing impact: affected functionality, counts (orders/customers/requests),
duration, SLO/error-budget effect.

## Timeline
Chronological list of key events with UTC timestamps (detection, trigger, mitigation,
resolution).

## Root Cause
Technical root cause, including the chain of contributing factors. Distinguish the
trigger from the underlying cause and state how other plausible explanations were
ruled out.

## Detection
How the incident was detected (alert vs. customer reports), when, and any gaps.

## What Went Well / What Went Wrong
Short bullet lists.

## Action Items
Concrete, ownable follow-ups (fix, detection, prevention).
